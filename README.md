# 山脊信使 RidgeLink · 山区应急通信辅助智能体

> 2026 大学生创新创业大赛 · 职教赛道 · 创意组
> 贵州电子科技职业学院 · 现代通信技术

一个**不需要服务器、不需要装软件、断网也能跑**的应急通信指挥辅助系统演示：
把「断网、断路、断链」的山区灾害现场，做成可推演、可交互、可复盘的一体化网页 + Android App。

---

## 这是什么

灾害来临时，最难的不是没有设备，而是不知道**先救哪里、链路怎么架、资源怎么分**。

山脊信使不造卫星、不造电台，它做应急通信的「参谋部」：

| 智能体 | 干什么 |
|---|---|
| 感知 | 融合基站退服告警、光缆断点、村级报灾、卫星云图降水 |
| 研判 | 按人口 / 道路 / 淹没范围排序受灾点，识别失联村寨 |
| 规划 | DEM 地形视距 + 菲涅尔余隙 + 链路预算，算出中继该架哪座山 |
| 调度 | 在卫星站 / 无人机 / PDT / 油机的约束下排任务序列 |
| 复盘 | 自动生成时间线、链路余量、改进建议 |

技术核心不是「接大模型」，而是**把通信工程师的经验写成可计算的模型**：

```
视距判断  →  DEM 高程采样 + 地球曲率 + 菲涅尔区
链路预算  →  FSPL + 天线增益 + 馈线损耗 vs 接收灵敏度
选路降级  →  地面基站 → 微波中继 → 卫星直连（北斗短报文 / 天通）→ PDT
```

页面里所有地形、链路、淹没范围计算，都在**浏览器本机 JS** 里完成，没有一次后端请求。

### 真实场景页做了什么

页面收成 **3 个 Tab**，一个入口看全，案例只保留 **2021—2026 最近五年**：

- **01 实景地图** —— 贵州全省一图总览（9 个市州驻地 + 8 个真实灾害点位，按灾种着色），点击城市弹出「城市风险速览」；下方是榕江 / 镇远两套河谷实景推演，可切换水位、看淹没范围、点选村寨做链路计算。
- **02 灾情案例** —— 四类灾害各一个主案例，同一张卡片里带 KPI、最近一次、可展开的时间线 / 通信影响 / RidgeLink 打法 / 本地示意图，同类型近年案例收在卡片底部。
- **03 复盘工具** —— 时间线复盘、48 小时处置链路、导入自己的村寨数据三件事合成一页，顶部有快捷跳转。

1. **真实地理实景** —— 榕江古州、忠诚、寨蒿、平永、八开、计划等真实乡镇，都柳江—寨蒿河—平永河三河汇流关系；镇远古城、石屏山、蕉溪、报京等真实地名；全省图另标大方、贵定、松桃—德江、普安等真实点位；
2. **真实事件时间线** —— 榕江 6·24 实测洪峰 256.71 m（超保证 5.21 m）、流量 1.14 万 m³/s，6·28 Ⅰ级响应、全城警报、转移 11992 户 41574 人；镇远洪峰 465.5 m、流量 3235 m³/s、转移 6000 余人；
3. **真实数据可导入** —— 支持粘贴 / 导入 CSV 点位数据，现场生成失联推演；
4. **真实业务流程** —— 从模型触发到指挥长审批、链路开通、复盘归档的完整闭环。

链路按 **地面基站 → 微波中继 → 卫星直连（北斗短报文先通 / 天通语音）** 逐级降级；卫星直连不依赖地面网，但需北斗 / 天通专用终端或支持卫星通信的机型。

> 数据口径在页面上明确区分：**公开报道**（真实事件）/ **推演**（模型计算）/ **示意**（地图非测绘成果）。2019 水城「7·23」、2008 凝冻只作历史背景一句话，不进入案例主列表。

## 怎么跑

### 方式一：直接双击

```text
index.html
```

纯静态，无构建、无依赖、无 CDN，双击就能开。

### 方式二：本地起服务（推荐，能测离线缓存）

```powershell
node serve.js          # 需要 Node.js，监听 8931
# 打开 http://127.0.0.1:8931/index.html
```

### 方式三：手机访问

```powershell
powershell -ExecutionPolicy Bypass -File .\start-public.ps1
```

脚本会自动起静态服务 + 下载并启动 cloudflared 隧道，并把公网地址写进 `public-url.txt`。
手机浏览器打开即可，**不需要填 IP**。电脑关机或隧道退出后地址失效，重跑脚本会拿到新地址。

## 离线能力（三层）

| 层级 | 实现 |
|---|---|
| 应用离线 | PWA（`manifest.webmanifest` + `sw.js`）缓存 3 个页面与图标；Android APK 直接读本地 `assets` |
| 智能体离线 | 规则引擎 + 预案库全部前端运行，断网不影响推演 |
| 对外通信 | 北斗短报文（140 B 单包）、卫星便携站、PDT、短波 —— 演示中体现为链路降级策略 |

页面右上角有**在线 / 离线模式**状态条：断网自动变「离线模式 · 本机推理中」，点击可看当前模式说明。

### 手机安装成 App

1. 手机浏览器（Chrome / Edge / Safari）打开公网地址；
2. 菜单 → **添加到主屏幕 / 安装应用**；
3. 打开一次让缓存写完，之后**飞行模式也能进**。

> 微信内置浏览器不支持安装，请用系统浏览器打开。
>
> 成功打开一次后，3 个页面已写入手机本地缓存；**即使电脑关机、公网隧道失效，已安装的 PWA 仍可离线打开**（清除浏览器数据或换手机后需重新打开一次）。
> 需要「换手机也能装、完全不依赖浏览器缓存」时，使用下方的 Android APK。

## Android APK

`android-apk/` 是一个原生 WebView 壳工程，加载 `file:///android_asset/www/index.html`，完全离线。

- 包名 `com.ridgelink.app`，minSdk 21，targetSdk 34
- 无 AndroidX、无第三方依赖，Kotlin 单 Activity
- **直接下载（Gitee）：** [`download/RidgeLink-2.2.apk?v=2.2`](https://gitee.com/lxylxyone/ridge-link/raw/apk-2.2/download/RidgeLink-2.2.apk)（约 1.2 MB）
- 安装后**完全离线**：页面、地形计算、链路预算都在手机本地运行，不需要电脑、不需要公网；首次安装需在系统设置中允许「安装未知来源应用」。
- 云端打包教程（备用）：见 [`android-apk/云打包教程.md`](android-apk/云打包教程.md)

改了网页后必须同步进 APK，否则 App 里还是旧页面：

```powershell
cd android-apk
powershell -ExecutionPolicy Bypass -File .\sync-web.ps1
```

02解决方案

五个专业智能体，
把通信保障串成一条流水线

不替代卫星电话和无人机，只做应急通信的“参谋部”：数据合到一张图，算完给出链路和任务单。

01 / 感知

多源融合

告警、气象、路况、北斗回传与群众上报合成一张图。

02 / 研判

影响评估

逐村算覆盖，排出先保谁。

03 / 规划

链路设计

地形加链路预算，给出微波、中继、卫星、PDT 组合。

04 / 调度

任务编排

按资源和道路约束，排谁先到、带什么、走哪条路。

05 / 复盘

过程还原

留时间线与余量数据，变成下次的预案。

感知接入网管、气象、交通、北斗与群众上报。
研判算受损范围、受影响人口与优先级。
规划做视距分析，输出多链路组合。
调度在资源与道路约束下出任务单。
复盘还原处置过程，沉淀成预案。

06创新点

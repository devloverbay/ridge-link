山脊信使

当山路断了，让信息先到。

面向山区“断网、断路、断链”极端场景，多智能体把灾情数据变成可执行的通信保障方案——3 分钟完成研判、链路规划与资源调度。

THE PROBLEM
01

灾害来临时，最难的不是没有设备
而是不知道“先救哪里、怎么连通”

山区村寨分散、地形切割强烈。一场山洪就能同时造成断电、断网、断路，让灾区在黄金 72 小时里变成信息孤岛。2025 年 6 月，榕江“6·24 / 6·28”两轮洪水转移 41574 人。

THE SOLUTION

指挥大脑 + 五大智能体
把“通信保障”做成一条闭环

感知 → 研判 → 规划 → 调度 → 复盘，五个专业智能体协同作战；公网中断时仍可在边缘本地运行。

CORE CAPABILITY
02

六个真正能在“三断”现场用上的能力

灾情一张图、地形感知链路规划（地面中继 → 卫星直连）、资源一键调度、北斗短报文压缩、离线边缘智能体、全流程复盘报告。

SCENARIOS
03

从贵州山地出发，适配四类高频灾害

暴雨山洪（榕江 2025）、地震滑坡（水城 2019）、森林火灾（水城—普安 2024）、冰雪冻雨（贵阳 2008）。同一套智能体，通过场景模板快速切换。

INNOVATION · 算法
04

把模型接进通信工程

DEM 视距分析 + 菲涅尔余隙 + 链路预算，让智能体的建议能落到具体站址、架高和天线方位。

INNOVATION · 调度

资源约束下的可执行调度

在道路中断、电量有限、人员不足的约束下，自动排出“谁先到、带什么、走哪条路”。

INNOVATION · 报文
05

北斗短报文，语义压缩到 140 字节

冗长通知压缩后单包下发：393 B → 116 B，断网时也能把关键指令送到村组干部手上。

VALUE
06

黄金 72 小时，通信恢复每提前 10 分钟

3 分钟生成方案 · 0 公网依赖 · 离线边缘可运行。山脊信使希望成为山区基层“用得起、学得会、断网也能用”的应急通信参谋。

ROADMAP
